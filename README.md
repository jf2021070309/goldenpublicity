# Golden Publicity

Sitio web oficial y catálogo de modelos / edecanes para **Golden Publicity**, desarrollado con **Astro**.

## 🚀 Estructura del Proyecto

```text
goldenpublicity/
├── public/
├── src/
│   ├── components/       # Componentes modulares (Header, HeroSlider, Equipo, Servicios, Contacto, etc.)
│   ├── layouts/          # Plantilla base con OpenGraph y SEO
│   ├── styles/           # Estilos globales y paleta de diseño
│   └── pages/
│       └── index.astro   # Página principal
├── package.json
└── astro.config.mjs
```

## 🧞 Comandos

Desde la carpeta del proyecto (`c:\Users\Jaimeelias\Documents\Proyectos\rea\goldenpublicity`):

| Comando | Acción |
| :--- | :--- |
| `npm run dev` | Inicia el servidor local en `http://localhost:4321/` |
| `npm run build` | Compila el sitio estático para producción en `./dist/` |
| `npm run preview` | Previsualiza el build de producción |
